name: tailwind
description: Apply the repository's Tailwind and utility-CSS conventions when editing JSX, TSX, Tailwind config, or global CSS.
---

Use mobile-first utilities, logical properties for direction-sensitive layout, and `clsx` or `cva` for dynamic class composition. Keep utilities close to semantic HTML, avoid bespoke CSS when utilities cover the need, and reserve `@apply` for the project's dedicated global CSS files. Follow project conventions when they differ.
